# RoadSight
Road debris detection and rear-vehicle warning system

인식이 어려운 상황에서의 도로 낙하물 탐지 성능 개선 및 후방 차량 경고 시스템

## 프로젝트 소개
AI P-실무 4분반 6조 프로젝트

낙하물 객체 중심의 코너케이스 합성 데이터를 활용하여
인식이 어려운 상황에서의 탐지 성능 개선 효과를 검증
검출 결과를 후방 차량 경고 시연으로 연결

## 역할 분담
| 팀원 | 담당 |
|---|---|
| 신승훈 | 데이터 전처리, 모델 학습·평가, 보고서 통합 |
| 김수민 | 객체 추출, 코너케이스 합성, 합성 라벨·품질 검토 |
| 이준혁 | Zero-DCE 비교 실험, 경고 시스템·시연, 발표자료 통합 |

## 저장소 구성
| 폴더 | 내용 |
|---|---|
| data | 전처리 코드, 분할 목록, 메타데이터 CSV |
| synth | 객체 추출·합성 코드, 생성 설정 |
| train | 학습·평가 코드, 실험 설정, 결과 CSV |
| demo | 영상 처리, 차로 판단, 경고 송수신 |

## 비교 실험 계획
| 구분 | 방법 |
|---|---|
| B1 | 원본 데이터로 학습 |
| B2 | B1 모델 추론 전 Zero-DCE 보정 적용 |
| B3 | 원본 + 이미지 전체 야간화 합성 데이터로 학습 |
| 제안 | 원본 + 객체 중심 코너케이스 합성 데이터로 학습 |
